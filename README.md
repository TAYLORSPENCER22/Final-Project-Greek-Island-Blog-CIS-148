# Greek Island Gal — Travel Blog

A simple multi-page travel blog about the Greek Islands, built with plain HTML & CSS as my final project for CIS 148. This was my first web project. (May 2024)

 **Live site:** https://taylorspencer22.github.io/Final-Project-Greek-Island-Blog-CIS-148/index.html

## Pages

- **Home** (`index.html`) — intro to Greece and the islands
- **Destinations** (`destinations.html`) — links out to island detail pages:
  - Santorini, Mykonos, Crete (`sub html/*.html`)
- **History** (`history.html`) — Greek history, with an audio clip
- **About** (`about.html`) — about the project/author, with a downloadable PDF

## Tech

- HTML5 & CSS3
